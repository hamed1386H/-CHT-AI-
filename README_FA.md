# CHT AI نسخه ۰.۶ — دستیار صوتی با گفت‌وگوی هوشمند و حافظه مکالمه

## امکانات نسخه ۰.۴
- همه قابلیت‌های محلی نسخه ۰.۳ حفظ شده‌اند.
- گفت‌وگوی آنلاین با مدل هوش مصنوعی از طریق API سازگار با OpenAI Chat Completions.
- نگهداری آخرین ۱۲ پیام مکالمه برای فهم سؤال‌های پیوسته و پاسخ با توجه به زمینه گفتگو.
- بازیابی تاریخچه پس از بستن و بازکردن برنامه.
- دکمه پاک‌کردن تاریخچه گفتگو با تأیید کاربر.
- اعتبارسنجی وجود نشانی سرویس، مدل و کلید؛ فقط HTTPS پذیرفته می‌شود.

- رابط فارسی و راست‌چین‌پذیر ساده با ورودی متن و فرمان صوتی فارسی
- پاسخ صوتی با Android TextToSpeech (در صورت نصب موتور/صدای فارسی)
- نمایش برنامه‌های قابل اجرا و باز کردن برنامه با نام آن
- پنل وای‌فای، تنظیمات بلوتوث، تنظیمات عمومی، باتری و دسترس‌پذیری
- تنظیم صدای رسانه از داخل برنامه
- تنظیم روشنایی کلی پس از اعطای مجوز ویژه «Modify system settings»؛ بدون مجوز فقط روشنایی پنجره خود برنامه تغییر می‌کند
- روشن/خاموش کردن چراغ‌قوه با Camera2
- روشن/خاموش کردن حالت مزاحم نشو پس از اعطای دسترسی ویژه Notification Policy
- اتصال اختیاری به API سازگار با قالب OpenAI Chat Completions از طریق HTTPS
- ذخیره نشانی سرویس، مدل و کلید API در SharedPreferences خصوصی برنامه

## راه‌اندازی هوش مصنوعی
۱. برنامه را اجرا کن و «تنظیم هوش» را بزن.
۲. نشانی کامل HTTPS سرویس سازگار با `/chat/completions`، نام مدل و کلید API را وارد کن.
۳. ذخیره کن و پیام متنی یا صوتی بفرست. پیام‌هایی که فرمان محلی شناخته نشوند به مدل ارسال می‌شوند. آخرین ۱۲ پیام برای حفظ پیوستگی گفتگو به مدل فرستاده می‌شود؛ با دکمه «پاک‌کردن گفتگو» می‌توانی این تاریخچه را حذف کنی.

نکته: این پروژه خودش مدل هوش مصنوعی یا اعتبار API رایگان ارائه نمی‌کند. برای پاسخ آنلاین به اینترنت، سرویس سازگار و کلید معتبر نیاز است. کلید را محرمانه نگه دار؛ در این نسخه در فضای خصوصی برنامه ذخیره می‌شود اما رمزنگاری اختصاصی با Android Keystore پیاده‌سازی نشده است. از دستگاه مشترک استفاده نکن و پس از آزمایش کلید را در صورت نیاز لغو/تعویض کن.

## محدودیت‌های هوش مصنوعی
- این نسخه موتور مدل را داخل APK حمل نمی‌کند؛ هوش واقعی آنلاین به اینترنت، سرویس‌دهنده مدل و کلید API معتبر نیاز دارد.
- برنامه کلید را در SharedPreferences خصوصی نگه می‌دارد؛ در این نسخه رمزنگاری اختصاصی Android Keystore هنوز اضافه نشده است. برای انتشار عمومی باید این بخش تقویت شود.
- مدل زبانی به‌تنهایی مجوز کنترل سیستم‌عامل ندارد. فرمان‌های دستگاه فقط از مسیر قابلیت‌های محلی پیاده‌سازی‌شده اجرا می‌شوند؛ مدل نباید ادعا کند تنظیمی را تغییر داده است.
- قابلیت حافظه فعلی فقط تاریخچه کوتاه مکالمه است، نه حافظه دائمی شخصی یا آموزش مدل.

## محدودیت‌های واقعی اندروید
- برنامه عادی نمی‌تواند بدون مجوزهای ویژه و تأیید کاربر به تمام تنظیمات و داده‌های گوشی دسترسی داشته باشد.
- روشن/خاموش کردن مستقیم وای‌فای توسط برنامه‌های عادی در نسخه‌های جدید اندروید محدود شده؛ این برنامه پنل رسمی وای‌فای را باز می‌کند.
- تغییر وضعیت بلوتوث مستقیم نیز در نسخه‌های جدید محدود است؛ برنامه صفحه تنظیمات بلوتوث را باز می‌کند.
- داده همراه، حالت پرواز، قفل صفحه، رمزها، مجوز برنامه‌های دیگر و تنظیمات امن سیستم قابل تغییر آزادانه نیستند.
- دسترسی Accessibility فقط از صفحه تنظیمات باز می‌شود. این نسخه سرویس Accessibility نصب یا فعال نمی‌کند.
- میکروفون فقط هنگام فشردن دکمه و پس از اجازه کاربر استفاده می‌شود؛ کلمه بیدارباش دائمی در این نسخه وجود ندارد.
- گفت‌وگوی ابری فقط وقتی کار می‌کند که API و کلید معتبر وارد شده باشد؛ هیچ کلید یا سروری داخل پروژه تعبیه نشده است.

## ساخت APK
پروژه نسخه ۰.۴ با Android Gradle Plugin 8.7.3، Kotlin 2.0.21، compileSdk 35 و minSdk 26 تنظیم شده است. برای ساخت، Android Studio و Android SDK لازم است. فایل APK آماده در این بسته نیست.

## نسخه ۰.۵ — مرکز مجوزها
- صفحه «مرکز مجوزهای CHT AI» برای مدیریت مجوزهای لازم اضافه شد.
- درخواست مجوزهای عادی میکروفون و دوربین (برای چراغ‌قوه) از داخل برنامه انجام می‌شود.
- صفحه‌های رسمی اندروید برای مجوز ویژه تغییر تنظیمات سیستم و دسترسی حالت مزاحم نشو باز می‌شوند.
- پس از بازگشت به برنامه، وضعیت مجوزها دوباره بررسی می‌شود و دکمه «مجوز داده شد / بررسی دوباره» نیز برای بررسی دستی وجود دارد.
- اندروید اجازه نمی‌دهد برنامه خودش مجوزها را به‌جای کاربر تأیید کند؛ کاربر باید در پنجره/تنظیمات رسمی دکمه اجازه دادن یا فعال‌سازی را انتخاب کند.
- فقط مجوزهای موردنیاز قابلیت‌های فعلی درخواست می‌شوند. اعلان‌ها، موقعیت مکانی، مخاطبین، پیامک و Accessibility درخواست نمی‌شوند چون در قابلیت‌های فعلی استفاده ندارند.


## نسخه ۰.۶ — پل اجرای فرمان با تأیید کاربر
- مدل هوش مصنوعی می‌تواند برای درخواست‌های دستگاه، پیشنهاد فرمان را در قالب JSON ساخت‌یافته برگرداند.
- فرمان پیشنهادی قبل از اجرا در پنجره تأیید نمایش داده می‌شود؛ کاربر می‌تواند «تأیید و اجرا» یا «لغو» را انتخاب کند.
- فرمان‌های پیشنهادی فقط از فهرست محدود قابلیت‌های محلی موجود عبور می‌کنند؛ فرمان خارج از فهرست اجرا نمی‌شود.
- اجرای نهایی از توابع محلی برنامه عبور می‌کند و مدل مستقیماً به APIهای سیستم‌عامل دسترسی ندارد.
- فرمان‌های فوری محلی که کاربر مستقیماً وارد می‌کند مانند نسخه‌های قبلی عمل می‌کنند؛ تأیید اضافه مخصوص پیشنهادهای صادرشده از مدل ابری است.

### محدودیت و ایمنی
این نسخه هنوز کنترل همه تنظیمات اندروید، اجرای خودکار در پس‌زمینه، Accessibility Service، دسترسی به پیامک/مخاطبین/اعلان‌ها یا اجرای فرمان دلخواه را ندارد. دسترسی‌ها فقط در حد قابلیت‌های صریحاً پیاده‌سازی‌شده و مجوزهای سیستم‌عامل هستند. برای انتشار عمومی، نگهداری کلید API باید به Android Keystore یا سرور واسط امن منتقل شود.


## نسخه 0.7.0 — صدا و عبارت بیدارباش
- انتخاب صدای گفتاری از میان صداهای فارسی و انگلیسی نصب‌شده در موتور TextToSpeech اندروید؛ انتخاب کاربر ذخیره می‌شود.
- حالت گوش‌به‌زنگ با عبارت «سلام CHT» از داخل برنامه و با دکمه فعال/غیرفعال می‌شود. پس از شنیدن عبارت، فرمان بعدی را اجرا می‌کند یا اگر فرمان همراه عبارت گفته شود همان را پردازش می‌کند.
- حالت گوش‌به‌زنگ فقط در زمان باز بودن برنامه و حضور آن در پیش‌زمینه طراحی شده است؛ با خروج از صفحه/بسته‌شدن برنامه متوقف می‌شود. برای بیدارباش واقعی در پس‌زمینه به سرویس foreground، اعلان دائمی و موتور تشخیص کلیدواژه آفلاین نیاز است و در این نسخه پیاده‌سازی نشده است.
- صداهای اختصاصی ChatGPT در APK قرار نگرفته‌اند؛ فهرست صداها را موتور گفتار نصب‌شده روی دستگاه فراهم می‌کند. برای صدای فارسی بیشتر، بسته‌های صوتی فارسی را در تنظیمات Text-to-speech گوشی نصب کن.


## نسخه ۰.۸ — سرویس گوش‌به‌زنگ دائمی
- تشخیص عبارت «سلام CHT» در یک Foreground Service مستقل از صفحه Activity اجرا می‌شود.
- سرویس با اعلان دائمی و اقدام «توقف گوش‌به‌زنگ» قابل مشاهده و کنترل است.
- با بستن صفحه یا کشیدن برنامه از فهرست اخیرها، سرویس عمداً متوقف نمی‌شود.
- به دلیل محدودیت اندروید، شروع سرویس میکروفون باید در حالی انجام شود که کاربر برنامه را باز کرده و مجوز میکروفون/اعلان را داده باشد.
- بعد از شنیدن عبارت بیدارباش، برای ادامه تعامل باید اعلان را لمس کنی و وارد برنامه شوی؛ اندروید اجرای خودکار Activity از پس‌زمینه را محدود می‌کند.
- گزینه START_STICKY فقط درخواست بازراه‌اندازی پس از توقف غیرعمدی فرایند است و تضمین نمی‌کند سازنده گوشی یا سیستم سرویس را همیشه زنده نگه دارد. در تنظیمات باتری گوشی، محدودیت باتری CHT AI را روی حالت بدون محدودیت قرار بده و در صورت وجود، Autostart را فعال کن.
- این سرویس صدای محیط را برای تشخیص عبارت بیدارباش پردازش می‌کند؛ از آن در مکان‌های خصوصی دیگران بدون رضایت استفاده نکن.


## نسخه ۰.۹ — پایداری بیشتر سرویس گوش‌به‌زنگ
- سرویس میکروفون foreground با اعلان دائمی مستقل از صفحه اصلی اجرا می‌شود و پس از بسته‌شدن Activity به کار ادامه می‌دهد.
- قفل بیدارماندن پردازنده (PARTIAL_WAKE_LOCK) برای کاهش توقف شنود هنگام خاموش‌شدن صفحه اضافه شد؛ مصرف باتری بیشتر خواهد شد.
- تلاش مجدد تشخیص گفتار پس از خطاها مدیریت‌شده شده و هنگام توقف سرویس، تلاش مجدد لغو می‌شود.
- درخواست مجوز اعلان پس از تأیید، اکنون ادامه فعال‌سازی سرویس را انجام می‌دهد.
- مرکز مجوزها گزینه حذف محدودیت بهینه‌سازی باتری و میانبر تنظیم شروع خودکار شیائومی را دارد؛ نتیجه به نسخه MIUI/HyperOS و تنظیمات گوشی بستگی دارد.
- شروع خودکار شنود پس از راه‌اندازی مجدد گوشی عمداً اضافه نشده است؛ نسخه‌های جدید اندروید شروع سرویس میکروفون از پس‌زمینه/بوت را محدود می‌کنند. کاربر باید سرویس را یک‌بار از داخل برنامه فعال کند.
- با انتخاب «توقف گوش‌به‌زنگ» در اعلان، میکروفون آزاد و قفل بیدارماندن رها می‌شود.

این نسخه سورس پروژه است؛ ساخت و آزمایش APK باید با Android SDK و روی دستگاه واقعی انجام شود. شنود دائمی باتری مصرف می‌کند و ممکن است موتور تشخیص گفتار گوشی برای شنود پیوسته محدودیت داشته باشد.


## بسته رابط کاربری J.A.R.V.I.S ULTIMATE نسخه 1.0.2
- صفحه اصلی با تم مشکی، خطوط و پنل‌های آبی/فیروزه‌ای، کارت‌های کنترل و نوار وضعیت شناور داخل برنامه بازطراحی شد.
- گوی هولوگرافیک متحرک با Canvas و بدون وابستگی خارجی اضافه شد. این گوی شاخص بصری است و داده سه‌بعدی/رندر واقعی ندارد.
- چیدمان برای صفحه موبایل و پیمایش عمودی طراحی شده است.
- نام برنامه در لانچر به J.A.R.V.I.S ULTIMATE تغییر کرد.
- عبارت بیدارباش سرویس به «سلام هوش» تغییر داده شد؛ تشخیص گفتار همچنان به موتور گفتار نصب‌شده در اندروید وابسته است.
- نوار شناور فعلی داخل صفحه برنامه است و جایگزین Dynamic Island سیستمی یا نمایش روی برنامه‌های دیگر نیست.

این بسته سورس است. برای تأیید نهایی باید با Android Studio و SDK 35 ساخته و روی دستگاه واقعی آزمایش شود. این محیط امکان اجرای Build اندروید و تست روی Redmi Note 13 را نداشته است.

## اتصال Gemini (نسخه 1.0.5)
برای فعال‌کردن گفت‌وگوی آنلاین، از Google AI Studio کلید Gemini API بساز و در برنامه از مسیر تنظیمات > تنظیم سرویس و API وارد کن. مدل پیش‌فرض `gemini-2.5-flash` است. سهمیه رایگان به شرایط و محدودیت‌های حساب و مدل وابسته است و تضمین نامحدود ندارد. کلید را محرمانه نگه دار؛ قراردادن کلید در APK برای انتشار عمومی توصیه نمی‌شود.

### نسخه 1.1.0
صفحه اصلی بدون کارت دسترسی سریع است. از تنظیمات، «فعال‌سازی جزیره شناور» را بزن و مجوز نمایش روی سایر برنامه‌ها را در اندروید تأیید کن. دکمه ذره‌بین جزیره DuckDuckGo را باز می‌کند. برای آهنگ‌ها، فرمان «آهنگ بزار» را بگو و مجوز موسیقی را تأیید کن؛ فرمان‌های «آهنگ بعدی»، «آهنگ قبلی»، «آهنگ تصادفی بزار» و «آهنگ رو متوقف کن» نیز پشتیبانی می‌شوند. جست‌وجوی نام آهنگ یا خواننده فقط در فایل‌های صوتی گوشی انجام می‌شود.
